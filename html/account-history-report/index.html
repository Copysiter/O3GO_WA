Интерпретация

В интерфейсе считаем, что `account.number` однозначно указывает на один аккаунт. Поэтому отчет показывает сам аккаунт как основной объект, без режима списка.

История строится вокруг `account.id = 1842`: все сессии выбираются по этому ID, затем сообщения выбираются по ID найденных сессий. Android-устройства показывают текущую привязку и устройства владельца аккаунта.
