# Изменения контекста проекта

## 2026-08-08

### Добавлено
- Обзор проекта: описание системы управления WhatsApp-аккаунтами, две поверхности API (admin + ext), назначение, системный контекст, ключевые технологии
- Архитектура: слоистая модель, компоненты с путями, границы ответственности, потоки запросов для admin и ext API, стратегии интеграции и ошибок, управление состоянием, расширяемость
- Технологический стек: Python 3.11, FastAPI, SQLAlchemy 2.0 async, Pydantic 2, PostgreSQL 12, JWT, API Key, APScheduler, httpx
- Структура репозитория: организация app/ по слоям (api, crud, models, schemas, services, jobs, adapters, core), директории верхнего уровня, конфигурация
- Конвенции: разделение ответственности, стиль кода (PEP 8, pylint, flake8, mypy), именование, правила тестирования, запрещённые практики
- Ограничения: Python 3.11, async-only I/O, PostgreSQL, локальный файловый storage, архитектурные границы, инфраструктурные ограничения
- Интеграции: PostgreSQL, Message API (campaigner.o3go.ru), Android-приложения, внешние системы рассылки, Nginx — подход и расположение кода

### Причина
Начальная генерация контекста проекта на основе инспекции репозитория. wa-admin/ исключён из учёта (черновик). Внешнее API классифицировано как универсальный интеграционный интерфейс.
