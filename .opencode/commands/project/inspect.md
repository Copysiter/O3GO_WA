Загрузить скилы `project-context` и `template-system` перед началом.

Инспектировать репозиторий и сгенерировать проектную документацию.

## Шаг 1: Сканирование репозитория

Исследовать кодовую базу:

- Дерево директорий (верхние 2-3 уровня): `find . -maxdepth 3 -type d`
- Манифест пакетов: requirements.txt, pyproject.toml, setup.py, setup.cfg, package.json, go.mod, Cargo.toml
- Точки входа: main-файлы, роутеры, обработчики, CLI-команды
- Фреймворки и библиотеки: импорты, зависимости
- База данных: миграции, конфиг ORM, файлы схем
- Messaging: конфиги очередей, обработчики событий, pub/sub
- Аутентификация: auth middleware, OAuth конфиг, JWT
- Конфигурация: docker-compose, .env.example, CI/CD файлы
- Тесты: директории тестов, фреймворки, фикстуры
- Интеграционные клиенты: HTTP-клиенты, SDK-обёртки, адаптеры

## Шаг 2: Предложить модель проекта

Представить находки как структурированное предложение:

```
Тип проекта: ...
Язык: ... (только мажорная версия)
Фреймворк: ...
Архитектурный стиль: ... (уверенность: высокая/средняя/низкая)
База данных: ...
Messaging: ... (или "не обнаружено")
Аутентификация: ... (или "не обнаружено")
Тестовый фреймворк: ...
Ключевые директории: ...

Неуверен:
- [элемент]: [почему]
```

Попросить пользователя подтвердить, исправить или дополнить.

**СТРОГО ПО ОДНОМУ ВОПРОСУ.** Если нужно уточнение — задать один вопрос, дождаться ответа, затем следующий. Не группировать несколько вопросов в одном сообщении.

## Шаг 3: Генерация документации

После подтверждения:

1. Прочитать шаблоны из `.opencode/templates/project/`
2. Заполнить все 8 проектных файлов по правилам скила `template-system`
3. Требования к качеству:
   - Каждая обязательная секция: минимум 2-3 полных предложения
   - Описывать компоненты по роли, а не по пути к директории
   - Списки технологий: название + назначение, только мажорные версии
   - Не дублировать одни и те же утверждения в разных файлах
4. Удалить маркеры шаблонов, заменить все placeholder'ы
5. Установить frontmatter `status` для каждого файла
6. Добавить запись в `.opencode/project/changes.md`

Сообщить, что сгенерировано и что осталось незаполненным.
