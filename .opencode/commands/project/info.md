Прочитать проектную документацию и представить компактную сводку в чате.

## Процесс

1. Прочитать следующие файлы из `.opencode/project/`:
   - `overview.md`
   - `stack.md`
   - `architecture.md`
2. Извлечь ключевые характеристики проекта
3. Представить компактную сводку

## Формат вывода

```
Проект: {название или описание}
Тип: {backend API / веб-приложение / CLI / библиотека / ...}
Язык: {язык и мажорная версия}
Фреймворк: {основной фреймворк}
Архитектура: {архитектурный стиль}
База данных: {технология БД или "отсутствует"}
Messaging: {система сообщений или "отсутствует"}
Аутентификация: {подход к auth или "отсутствует"}
Интеграции: {количество внешних систем}
Основные модули: {главные директории или компоненты}
```

Если какая-либо информация недоступна или соответствующий файл не существует, указать «неизвестно» явно.  
Не выводить предположения вместо отсутствующих данных.

Операция выполняется в режиме только чтения. Не модифицировать никакие файлы.
