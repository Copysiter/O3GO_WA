[TEMPLATE_EXAMPLE]

1. Access Point проверяет права на вызов REST метода до маршрутизации в сервис  
2. Сервис проверяет предметные разрешения (ks.*) через Casbin Enforcer  
3. Роли извлекаются из JWT-токена Keycloak через AuthContext  
4. Owner наследует права Manager и IT Admin через иерархию ролей Casbin  
5. Сервисы регистрируют свои методы и политики в Access Point через REST API  
6. Изменения политик применяются без перезапуска через database hooks  

[/TEMPLATE_EXAMPLE]

RBAC на базе Casbin с разделением модели (model.conf) и данных (policy.csv).
