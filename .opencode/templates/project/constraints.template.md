- JSON-RPC является основным протоколом взаимодействия, REST-эндпоинты не используются для бизнес-операций
[/TEMPLATE_EXAMPLE]

- Доступ к базе данных осуществляется исключительно через слой репозиториев. Прямые SQL-запросы из сервисов или обработчиков не допускаются.
- Взаимодействие с внешними системами инкапсулировано в адаптерах. Прямые HTTP-вызовы из сервисного слоя запрещены.
- Политики авторизации являются единственным механизмом проверки прав. Хардкод ролей в коде через условия запрещён.
- Модули не должны импортировать внутренние файлы других модулей. Межмодульное взаимодействие — только через публичные интерфейсы.

[TEMPLATE_EXAMPLE]

- Pydantic-схемы ответов являются контрактом: удаление полей из существующих схем недопустимо
[/TEMPLATE_EXAMPLE]
